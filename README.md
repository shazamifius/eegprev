# Tutoriel d'installation locale

Ce tutoriel vous guidera pour installer et lancer le site web en local sur votre machine.

## Prérequis

- **Node.js**: Assurez-vous d'avoir Node.js installé. Vous pouvez le télécharger depuis [le site officiel de Node.js](https://nodejs.org/).

## Étapes d'installation

1. **Cloner le dépôt**

   Ouvrez un terminal et clonez le dépôt Git sur votre machine :

   ```bash
   git clone <URL_DU_DEPOT>
   ```

2. **Accéder au répertoire du projet**

   ```bash
   cd <NOM_DU_DOSSIER_DU_PROJET>
   ```

3. **Installer les dépendances**

   Installez toutes les dépendances du projet en utilisant npm :

   ```bash
   npm install
   ```

4. **Lancer le serveur**

   Une fois les dépendances installées, vous pouvez lancer le serveur :

   ```bash
   node index.js
   ```

5. **Accéder au site**

   Ouvrez votre navigateur et rendez-vous à l'adresse suivante :

   [http://localhost:3000](http://localhost:3000)

Vous devriez maintenant voir la page d'accueil du site. Vous pouvez vous inscrire et vous connecter pour tester les fonctionnalités.
